## Дүгнэлт

Fed-Ex аяллаар хамгийн олон буюу 4 bug олдсон. Энэ нь өгөгдлийн урсгал, тоолуурын зөрүүг мөшгөх зорилготой тул логик төвшний согогийг хамгийн сайн илрүүлсэн. Supermodel аялал (BUG-05, BUG-06) GUI-ийн харагдах байдал, мессежийн зөрүүг хурдан олсон. Тухайлбал, BUG-06-ийн буруу текст нь зөвхөн тайлбарын алдаа биш, хэрэглэгчийг төөрөлдүүлэхүйц сэтгэл зүйн нөлөөтэй болохыг ажиглав. Couch Potato аялал (BUG-07, BUG-08) validation-ийн цоорхойг GUI талд нотолсон. Saboteur аялал (BUG-09), сессийн 60 минутаас гадна тусад нь гүйцэтгэсэн ч хамгийн ноцтой олдворыг өгсөн: API талд validation огт байхгүй нь батлагдсан. Буруу JSON-д 400 биш 200, хоосон/буруу утгатай хүсэлтэд 400 биш 201 буцсан.

Fed-Ex аялалд хэт их цаг зарцуулснаас болж Saboteur аяллыг анх төлөвлөснөөр 60 минутын session дотор багтаасангүй. Дараагийн удаа аялал бүрт тэнцвэртэй цаг хуваарилах, цагаас хэтэрсэн бол тухайн аяллыг зогсоох хэрэгтэй гэж дүгнэж байна.

Charter-ийн хүрээнд шалгагдаагүй үлдсэн зүйл: Guidebook, Museum, Bad Neighborhood, Antisocial, All-Nighter, Rained-Out аялалууд.

Playwright-ийн автомат тест BUG-01 (тоолуурын зөрүү), BUG-02 (том/жижиг үсэг), BUG-07/08 (GUI validation), BUG-09 (API статус код) зэргийг assert-аар амархан барих боломжтой байсан, учир нь эдгээр нь тодорхой, давтагдах оролт/гаралттай. Харин BUG-05 (товчны өнгө), BUG-06 (мессежийн утга санааны зөрүү) зэрэг нь хүний нүдэнд л мэдэгдэх, скрипт тест анзаардаггүй харагдах байдал/утга-агуулгын согог байлаа.
