## BUG-09: API /api/books дээр validation бүрэн алгасагдаж, буруу JSON болон хоосон/буруу утгатай ном амжилттай нэмэгддэг

Орчин:
- Уншлагын жагсаалт v2.0
- Browser: Firefox
- OS: Linux Mint Cinnamon
- Огноо: 2026-10-20

Урьдчилсан нөхцөл:
- `node app.js` шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминалаас дараах хүсэлтийг илгээнэ (бүтэц эвдэрсэн, JSON биш бие):
```
curl -i -X POST localhost:3000/api/books -H "Content-Type: application/json" -d 'буруу JSON'
```
2. Дараа нь зөв бүтэцтэй боловч спецификацийн дүрмийг зөрсөн утгатай хүсэлт илгээнэ:
```
curl -i -X POST localhost:3000/api/books -H "Content-Type: application/json" -d '{"title":"","author":"","year":"abc"}'
```

Хүлээгдэж байсан: Спецификацийн дагуу ("API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана" мөн "Гарчиг, Зохиолч, Он гурван талбар бүгд заавал бөглөгдсөн байх ёстой... Он нь 1000-2100 хоорондох бүхэл тоо") хоёр хүсэлт аль аль нь `400 Bad Request` статустай, ойлгомжтой алдааны мессежтэй буцах ёстой бөгөөд ном нэмэгдэх ёсгүй.

Бодит үр дүн:
- 1-р хүсэлт (бүтэц эвдэрсэн JSON): `HTTP/1.1 200 OK` буцсан. 400 биш, бие ч хоосон.
- 2-р хүсэлт (хоосон гарчиг, хоосон зохиолч, тоон бус он `"abc"`): `HTTP/1.1 201 Created` буцаж, `{"result":"OK","id":4}` хариутайгаар шинэ ном амжилттай үүссэн.

Ноцтой байдал: Critical. Сервер талд validation огт байхгүй нь батлагдлаа. Спецификациас зөрсөн өгөгдлийг саадгүй нэвтрүүлж болохыг харуулж байна. Өгөгдлийн бүрэн бүтэн байдал хамгаалагдаагүй тул аливаа клиент (эсвэл муу санаатай хэрэглэгч) GUI-г тойрон эвдэрсэн өгөгдөл оруулах боломжтой.
